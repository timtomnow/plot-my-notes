The **Entries** tab lists everything you've logged, grouped by day. When the
list gets long, you can search and filter it down to what you're looking for.

## Before you start

- You need some logged entries. See [Log an entry](/help/log-an-entry).

## Steps

1. Open the **Entries** tab.
2. Type in the search box to match text in entry **titles** and **notes**.
3. Tap a **tag** chip to show only entries with that tag. Tap more than one to
   require all of them; tap **Clear tags** to reset.
4. Tap a tracking-type chip (or **All**) to limit the list to one type.
5. If nothing matches, tap **Clear filters** to start over.

## What you'll see

The header shows how many entries match out of the total, and the list updates
as you type and tap. Matching text in the results is highlighted.
