Plot My Notes doesn't run notifications itself — instead it builds a calendar
file (`.ics`) that you import into your phone's calendar. Your calendar then
reminds you on the schedule you chose, with a link that opens straight to the
right screen for logging.

## Before you start

- *(Optional)* Decide which tracking type the reminder should open to. You can
  also point it at the homepage.

## Steps

1. Open **Settings → Reminders**.
2. Set the **Event title** and **Message**. A link and small footer are added
   automatically.
3. Under **Link opens to**, choose **Homepage** or a specific **New entry** for
   one of your tracking types.
4. Set the **First occurrence** date and **Time**.
5. Choose how it **Repeats** — One time, Daily, Weekly, or Monthly. For weekly,
   pick the days; for repeating reminders, choose when it **Ends**.
6. Choose when the **Notification fires** (at event time, or minutes before).
7. Tap **Download calendar file**, then open the downloaded file to add it to
   your calendar.

## What you'll see

A confirmation says the calendar file is ready. Opening it adds the event (and
any repeats) to your calendar app. To change a reminder later, edit it in your
calendar — or generate a new file here.
