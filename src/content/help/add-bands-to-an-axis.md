**Bands** divide an axis into named groups, such as *Low*, *Okay*, and *Great*.
They're shaded behind your charts so you can see at a glance which range a score
falls into. Bands are entirely optional.

## Before you start

- You need an axis to add bands to. See
  [Create a custom axis](/help/create-a-custom-axis).
- Decide the breakpoints — each band covers from the previous breakpoint up to
  the value you set.

## Steps

1. Open **Settings → Axes**.
2. Tap the **edit** (pencil) button on the axis you want to band.
3. In the **Bands (optional)** section, tap **Add band**.
4. Give the band an optional **Label** and set its breakpoint value (the top of
   that band's range).
5. Pick a colour, or leave it on **Auto** for alternating shades.
6. Repeat for each band. The app sorts them by value and shows each band's
   range, e.g. `0 → 5`.
7. Tap **Save**.

## What you'll see

The Axes list shows how many bands the axis has. Wherever that axis appears on a
chart, the bands are shaded behind the data.
