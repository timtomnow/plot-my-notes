A **tracking type** is the thing you actually log day to day. It bundles one
axis (a simple **1D** scale) or two axes (a **2D** pair, like *Happiness* and
*Energy* together as *Mood*). Each type has its own colour so it's easy to spot
in lists and charts.

## Before you start

- Create the axes you want to use first. See
  [Create a custom axis](/help/create-a-custom-axis).
- A 2D type needs two **different** axes.

## Steps

1. Open **Settings → Tracking Types**.
2. Tap **New type** (or **Create type** if you have none yet).
3. Enter a **Name**, e.g. `Mood`.
4. Optionally add a **Short description** and a **Full description**.
5. Pick a **Color** for the type.
6. Leave **2D tracking** off for a single-axis type, or turn it on to use two
   axes.
7. Choose the **X axis**. If 2D tracking is on, also choose a **Y axis**.
8. *(Optional, 2D only)* Add **regions** to shade areas of the chart. See
   [Add regions to a 2D tracking type](/help/add-regions-to-a-2d-type).
9. Tap **Create**.

## What you'll see

The new type appears in the Tracking Types list, tagged **1D** or **2D** with
its axes and entry count. It now shows up as a chip on the **New entry** and
**Charts** screens.
