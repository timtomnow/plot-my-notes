**Regions** are coloured rectangles drawn on a 2D tracking type's chart and on
the input pad you use to log. They let you label areas of the plane — for
example, a *Calm* corner or an *Overwhelmed* quadrant. Regions are optional and
only apply to 2D types.

## Before you start

- You need a **2D** tracking type (one with both an X and Y axis). See
  [Define a tracking type](/help/define-a-tracking-type).

## Steps

1. Open **Settings → Tracking Types**.
2. Tap the **edit** (pencil) button on a 2D type, or create a new one with **2D
   tracking** turned on.
3. In the **Quadrants / regions (optional)** section, tap **Add region**.
4. Give the region an optional **Label**.
5. Set the rectangle's bounds: a **from** and **to** value for each axis.
6. Pick a colour for the region.
7. Add more regions if you like, then tap **Save**.

## What you'll see

The Tracking Types list notes how many regions the type has. When you log or
view this type, the coloured regions are shaded behind the 2D pad and the
scatter chart.
